# Xưởng phim hoạt hình — Công Nghệ 24H Media

Trang chỉ còn một công cụ: `/lam-phim`, làm phim hoạt hình kể chuyện ngắn.

1. Gõ ý chính, AI (Gemini) viết bảng cảnh.
2. Chép câu lệnh từng cảnh, dán vào Gemini để vẽ ảnh, tải ảnh lên.
3. Trang dựng video ngang 16:9 có giọng đọc AI và phụ đề ngay trên trình duyệt.

Bài làm dở và ảnh lưu trong trình duyệt (localStorage + IndexedDB), không có cơ sở dữ liệu.

Biến môi trường: xem `.env.example`.

Bản đầy đủ trước khi gỡ các tính năng quản lý Fanpage nằm ở thẻ git `ban-day-du-truoc-khi-xoa`.
